# 🎨 Frontend Design & Anti-UI Slop (2026 Standards)

Создание бескомпромиссных интерфейсов мирового уровня без типовой ИИ-штамповки (AI Slop).
Основано на официальном стандарте Anthropic `frontend-design`, UIZZE Anti-Slop и принципах Duarte + Norman.

## Главный закон
> Никогда не соглашайся на скучный серый интерфейс. Пользователь должен ощутить качество и премиальность (WOW-эффект) с первого взгляда.

## Манифест против AI Slop

| AI Slop (Запрещено) | Production-Grade 2026 (Обязательно) |
| :--- | :--- |
| Дефолтный Inter / Roboto везде | Характерный заголовочный шрифт (Outfit / Syne / Plus Jakarta Sans) + чистый читаемый body |
| Базовые цвета `#ffffff`, `#000000`, `gray-200` | Гармоничные палитры на CSS-переменных (HSL/OKLCH, глубокий даркмод `#0d1117`, акценты) |
| Одинаковые квадратные карточки в сетке 2x2 | Динамическая композиция: асимметрия, глубина, воздух, визуальный ритм |
| Мгновенные резкие ховеры без сглаживания | Плавные микро-переходы (`transition: all 0.2s cubic-bezier(0.16, 1, 0.3, 1)`) |
| Плоские серые рамки в 1px | Благородный стекломорфизм (`backdrop-filter: blur(12px)`), зеркальные блики (`box-shadow: inset 0 1px 0 rgba(255,255,255,0.12)`) |
| Разрозненные отступы наугад (7px, 13px) | Строгая шкала отступов (4px, 8px, 12px, 16px, 24px, 32px) |

## Архитектурный чеклист UI/UX

1. **Визуальная иерархия:** Единственный главный акцент на экран. Вторичные действия приглушены.
2. **Эргономика и аффордансы:** Кликабельные элементы имеют понятную форму, курсор pointer, явные состояния `:hover`, `:active`, `:focus-visible`.
3. **Микроанимации:** Легкий тактильный отклик при нажатии (`transform: scale(0.97)`), неоновое свечение активных режимов.
4. **Доступность (a11y):** Контраст текста к фону не менее 4.5:1, видимый фокус для клавиатуры, `prefers-reduced-motion`.
5. **Готовый код:** Никаких плейсхолдеров или незавершенных стилей — только законченный production-ready CSS/HTML/JS.
