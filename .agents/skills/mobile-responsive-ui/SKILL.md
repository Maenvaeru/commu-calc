# 📱 Mobile-First & Responsive Adaptive UI (2026 Standards)

Стандарт адаптивного и сенсорного проектирования интерфейсов от мобильных устройств до сверхшироких мониторов.
Основано на принципах Дона Нормана (сенсорные зоны), рекомендациях Apple HIG, Material Design 3 и стандарте CSS Container Queries.

## Главный закон
Интерфейс обязан безупречно работать при любом размере экрана, ориентации и типе ввода (палец, стилус, мышь, клавиатура). Никакого горизонтального скролла контента и некликабельных элементов.

## 1. Брейкпоинты и адаптивная сетка
- **Mobile Compact:** `320px – 480px` (смартфоны портретно, одноколоночная раскладка).
- **Mobile Landscape / Small Tablet:** `481px – 768px` (крупные телефоны, мини-планшеты).
- **Tablet / Laptop:** `769px – 1024px` (планшеты, нетбуки, переход на двухколоночную структуру).
- **Desktop Standard:** `1025px – 1440px` (ноутбуки и настольные мониторы).
- **Widescreen / 4K:** `1441px+` (ограничение максимальной ширины контента `max-width: 1400px; margin: 0 auto;`).

## 2. Сенсорная эргономика (Touch Ergonomics)
- **Минимальный тач-таргет:** Не менее `44x44px` (рекомендация iOS HIG / WCAG 2.2).
- **Зона большого пальца (Thumb Zone):** Главные кнопки действий размещаются в нижней трети экрана (Bottom Navigation, Sticky Action Bar). Деструктивные или редкие действия — в верхней.
- **Изоляция ховеров:** Стили `:hover` обязаны быть обернуты в `@media (hover: hover) and (pointer: fine)`, чтобы исключить паразитное залипание на сенсорных экранах.
- **Безопасные отступы (Safe Areas):** Учет вырезов и системных полос через `env(safe-area-inset-top)` и `env(safe-area-inset-bottom)`.

## 3. Респонсивная типографика и единицы
- **Флюидный размер шрифта:** Использование `font-size: clamp(min, preferred, max)` вместо жестких `px`.
- **Высота вьюпорта (Dynamic Viewport):** Использование `100dvh` вместо `100vh` для исключения скачков высоты при появлении экранной клавиатуры и мобильной адресной строки.
- **Контейнерные запросы:** Использование `@container (min-width: ...)` для модульных компонентов, адаптирующихся под размер родительского блока.

## 4. Чеклист адаптивной верификации
1. [ ] Корректный метатег `<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">`.
2. [ ] Отсутствие горизонтального скроллбара (`overflow-x: hidden` на корне или сетке).
3. [ ] Читаемость текста без зума (базовый кегль на мобильном ≥16px для инпутов, предотвращающий автозум iOS).
4. [ ] Быстрый отклик на тап (`touch-action: manipulation`).
