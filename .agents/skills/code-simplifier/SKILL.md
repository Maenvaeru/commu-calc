# 🧹 Code Simplifier & Clean Monolith (DHH Discipline)

Непрерывный автоматический рефакторинг, устранение оверинжиниринга, удаление паразитных абстракций и поддержание лаконичного монолита.
Основано на инженерной философии DHH (Majestic Monolith) и лучших практиках Claude Code simplification.

## Кредо
> Сложность — это главный враг надежности. Лучший код — это код, который не пришлось писать. Каждая лишняя прослойка, фабрика или интерфейс с одной реализацией обязаны быть удалены.

## Антипаттерны к немедленному устранению (Code Smells)

1. **Паразитный оверинжиниринг:**
   - Фабрики фабрик, абстрактные адаптеры к единственной библиотеке, преждевременные микросервисные фасады.
   - *Лечение:* Прямой вызов функции или метода в монолите. Конвенции над конфигурацией.
2. **Дублирование логики (Нарушение DRY):**
   - Копипаста валидаций, одинаковые regex, разрозненные пути форматирования строк.
   - *Лечение:* Единый хелпер или утилита прямого действия.
3. **Глубокая вложенность (Pyramid of Doom):**
   - 4+ уровня `if`, `try`, `switch`.
   - *Лечение:* Guard clauses (ранние выходы `if (!valid) return;`), плоская структура.
4. **Мертвый код и зомби-ветки:**
   - Закомментированные куски, неиспользуемые переменные, методы-пустышки.
   - *Лечение:* Безжалостное удаление. Git помнит историю, коду мусор не нужен.
5. **Мутации глобального состояния:**
   - Неконтролируемые сайд-эффекты через глобальные переменные без синхронизации.
   - *Лечение:* Атомарные функции с чистыми параметрами и предсказуемыми возвратами.

## Процедурный чеклист рефакторинга

1. **Изоляция:** Зафиксируй поведение существующими тестами или canary-скриптом.
2. **Сжатие:** Сократи код в 1.5–3 раза без потери семантики и читаемости.
3. **Устранение прослоек:** Объедини файлы, если абстракция существует только в одном месте.
4. **Проверка инвариантов:** Убедись, что внешние контракты (API/IPC/DOM) остались нерушимы.
