# Спецификация и Требования: Commu-Calc App (Windows + Android)

## 1. Описание задачи
Создание кросс-платформенного приложения для учета коммунальных платежей (Свет, Отопление, Вода) на базе предоставленных данных из `расчеты.txt`. Приложение должно сравнивать вводимые данные с предыдущим месяцем в реальном времени, иметь профессиональный дизайн с современной анимацией, и сохранять данные в Google Sheets.

## 2. Технологический стек
- **Фреймворк:** Flutter (Dart). Идеально подходит для одновременной сборки под Windows и Android, обеспечивает высокую производительность (60-120 fps) и позволяет легко реализовывать сложные, минималистичные и современные анимации.
- **Хранилище данных (База данных):** Google Sheets. 
- **Интеграция с Google Sheets (Backend/API):** 
  - Рекомендуется использовать **Google Apps Script** для создания легковесного промежуточного REST API. Это позволяет скрыть логику авторизации и избежать хранения Service Account Key прямо в коде клиентского приложения, что существенно повышает безопасность. 

## 3. Требования к UI/UX (Современный минимализм)
- **Цветовая схема:** Темная тема (Dark Mode) с высококонтрастными элементами из палитры Material 3 или светлая тема с эффектами Glassmorphism. Нейтральный фон, акценты на цифрах.
- **Типографика:** Механистичный, легко читаемый шрифт типа Inter или Roboto Mono для цифр.
- **Анимации:** 
  - Одометрические счетчики (Animated Counter) для отображения разницы (дельты). Завораживающий эффект при прокрутке цифр.
  - Плавные появления карточек (FadeIn + SlideUp) при загрузке.
  - Состояния загрузки с элегантными shimmer-эффектами.

## 4. Структура Данных и Модели
Поля для ввода на каждый месяц:
- **Дата** (автоматически или выбор из календаря)
- **Свет:** День (целое или с плавающей точкой)
- **Свет:** Ночь (целое или с плавающей точкой)
- **Отопление:** (с плавающей точкой, напр., 4.249)
- **Вода ГВС:** (целое, напр., 173)
- **Вода ХВС:** (целое, напр., 225)

# Журнал Ошибок и Решений (Logs of Errors and Solutions)

### Ошибка 1: Exception: Status code: 401 Unauthorized (Google Apps Script)
* **Симптомы:** Скрипт во Flutter возвращает 401 при POST запросе и отдает HTML страницу авторизации `<!doctype html>` при GET запросе.
* **Причина:** Неверные настройки Google Apps Script Web App Deployment. Доступ был установлен не на "Все" (Anyone), из-за чего Google требовал OAuth логин.
* **Решение:** В GAS необходимо создать Новое Развертывание (New Deployment), указав "Execute as: Me" и "Who has access: Anyone". Также в код Flutter (`lib/main.dart`) добавлена проверка: если сервер возвращает HTML со словом `Sign in - Google Accounts`, вызывать кастомное Exception с понятным текстом предупреждения для пользователя. 

### Ошибка 2: Пустой экран (только задний фон) при ошибке сети
* **Симптомы:** Интерфейс не отображается, видно только синий градиент.
* **Причина:** В виджете был применен `FadeTransition` со стартовой `opacity: 0.0`. Анимация прозрачности запускалась только в случае `if (response.statusCode == 200)`. При возникновении Exception контроллер анимации не стартовал, оставляя весь UI на экране абсолютно прозрачным (невидимым).
* **Решение:** В конструкции `try...catch...finally` запуск `_fadeController.forward()` перенесен в блок `finally` (с проверкой `if (mounted)`), чтобы интерфейс плавно появлялся в любом случае, даже если произошла ошибка API.

### Ошибка 3: Просадки FPS при перетаскивании окна и отсутствие начальных данных
* **Симптомы:** FPS проседал до 30 кадров при изменении размера окна, данные загружались как нули.
* **Причина:** `BackdropFilter` с радиусом размытия 50px поверх всего экрана критически нагружает CPU/GPU на Windows Desktop. Нули загружались потому что Google Apps Script при пустой таблице (менее 2 строк) возвращал пустой JSON.
* **Решение:** 
    1. Эффект размытия `BackdropFilter` был полностью удален. Вместо него внедрены `RadialGradient` элементы, имитирующие свечение сфер. Прирост производительности составил 100-200% (стабильные 60 FPS).
    2. Изменен код Apps Script: теперь, если таблица совершенно пустая, функция GET возвращает шаблонные данные за "21.02.26" (из `расчеты.txt`). Это служит стартовой точкой отсчета.

### Ошибка 4: Android-приложение не грузит данные из Google Sheets (SocketException, красная полоса ошибки)
* **Симптомы:** Скомпилированный APK на телефоне сразу при открытии показывает пустые значения (0) и красную полосу ошибки (Exception UI Snackbar). На Windows при этом всё работает.
* **Причина:** Версии Android-сборок в режиме `Release` по умолчанию не имеют прав на доступ к интернету. При попытке HTTP-запроса через пакет `http` операционная система Android сразу выбрасывает блокирующую ошибку безопасности.
* **Решение:** В файл `android/app/src/main/AndroidManifest.xml` вручную добавлено разрешение `<uses-permission android:name="android.permission.INTERNET"/>` перед тегом `<application>`. Приложение было пересобрано.
